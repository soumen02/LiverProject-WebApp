# Sample CT

`example_ct.nii.gz` is the public example scan from [TotalSegmentator](https://github.com/wasserth/TotalSegmentator)
(`tests/reference_files/example_ct.nii.gz`, Apache-2.0).

It is a 3 mm abdominal CT that cuts off the top of the liver. It is here so anyone can try the app, and it is
not the triple-phase, contrast-enhanced CT the models were trained for, so treat its results as a demo only.
